A modern, responsive **personal portfolio website** showcasing my projects, achievements, skills, and professional background. Built with a clean UI, smooth interactions, and performance in mind.

## 🚀 Features

- Responsive and mobile-friendly design
- Modern UI using glassmorphism and animations
- Featured projects with tech stack details
- Achievements and academic highlights
- About section with professional experience
- Resume download support

---

## 🛠 Tech Stack

This project is built using:

- **Vite** – Fast build tool
- **React** – UI library
- **TypeScript** – Type safety
- **Tailwind CSS** – Utility-first styling
- **shadcn/ui** – Reusable UI components
- **Lucide Icons** – Icon set

## 📂 Project Setup (Local Development)

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Steps

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate into the project
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at: `http://localhost:5173`
